# Strivon

Shelf monitoring for the Sensei challenge at JunctionX Lisbon 2026.
Input: ceiling-camera images and the planogram. Output: one JSON with
planogram_compliant and stock_level for each shelf area.

## Hard rules

- Never commit challenge data, images, planogram.json, keys or .env.
- All code is written during the hacking hours. Prior code is declared in the README.
- If a request clashes with these rules, say so before acting.
