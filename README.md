# Strivon

Shelf monitoring for fruit and vegetable sections, built at JunctionX Lisbon 2026 for the Sensei challenge.

Given a ceiling-camera image and the store planogram, Strivon tells staff for each shelf area whether it holds the right product and how full it is.

## Layout

- `backend/` Python: the pipeline that writes the predictions.
- `frontend/` React and shadcn/ui: the view for store staff.
- `data/` challenge images and planogram. Not committed.
