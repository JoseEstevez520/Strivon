# Slides

`strivon-slides.pptx` is the same story as the web deck, as a PowerPoint file: eight slides with one idea each, text and shapes you can edit, a fade between slides and each element fading in one after another without clicks.

- The font is Inter. Install it on the machine that presents, or PowerPoint will use another one and the layout will shift.
- It was checked in LibreOffice. The animations were not tried in PowerPoint or Keynote.
- It is an example to start from. For the sweep transition and the clips, use the web deck in `../web-deck/`.
